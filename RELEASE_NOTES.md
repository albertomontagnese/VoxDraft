VoxDraft 1.0 beta is a Mac menu bar dictation app. Press Control + Option + D to start speaking, then press it again to insert the transcript into the active text field.

It uses Apple's Speech framework, has local history and basic filler cleanup, and can optionally polish text with a local Hermes model through Ollama.

This build is ad hoc signed and is not Apple notarized. To run a downloaded build, macOS may require you to open it through Finder's Open command. Grant Microphone and Speech Recognition access on first dictation, then Accessibility access to insert text into other apps.

Requires macOS 14 or newer. Includes Apple Silicon and Intel binaries.
